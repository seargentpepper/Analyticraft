El espacio de trabajo

Tres vistas, una adopción inmediata

La interfaz replica la anatomía de Power BI Desktop —Cinta Ribbon, barra lateral de tres vistas, paneles acoplables y navegación por páginas— para que no haya curva de aprendizaje que pagar.

01

Vista de Informe

Lienzo analítico interactivo para organizar gráficos, tarjetas métricas y segmentadores. Arrastra campos, aplica filtros reactivos y compón la historia sobre el lienzo.

02

Vista de Datos

Cuadrícula de alta densidad para inspeccionar registros crudos, estrictamente de solo lectura. Editar celdas destruiría la Fuente Única de Verdad y provocaría discrepancias con el ERP y el CRM: para corregir se modifica el CSV original y se hace Hot Swap.

03

Vista de Modelo

Diagrama relacional para enlazar dimensiones y hechos mediante drag & drop, con cardinalidad 1 a *, auto-alineación en cascada y sugerencias heurísticas para principiantes.

Flujo de trabajo

El mismo flujo que Power BI, en cuatro pasos

Si ya has usado Power BI, esto te va a sonar: importar, modelar, diseñar, compartir. Si nunca lo has tocado, la interfaz incluye un tutorial guiado y consejos contextuales que te llevan de la mano hasta tu primer dashboard.

  1. 01

    Importar datos

    Carga uno o más archivos CSV locales desde la pestaña Inicio o el panel Campos. DuckDB detecta los tipos de columna automáticamente en milisegundos.

  2. 02

    Modelar relaciones

    Cambia a la Vista de Modelo para enlazar tablas de dimensiones con tablas de hechos mediante arrastre visual de columnas o con el botón de auto-detección.

  3. 03

    Diseñar el informe

    Arrastra campos hacia las tarjetas visuales —barras, líneas, áreas, donas, anillos o KPIs— y aplica filtros reactivos hasta que el relato quede claro.

  4. 04

    Compartir el dashboard

    Exporta el proyecto a un archivo .html autocontenido con un clic: listo para enviar por correo o mensajería sin servidores ni licencias.

Cero no es una cifra de marketing: es la ausencia de todo lo que te frena.

Tus archivos de ventas abren al instante, tus gráficos se dibujan mientras miras y el informe que te pidió dirección para mañana ya está en un archivo que puedes mandar por WhatsApp. Nada sale de tu equipo, nada caduca a fin de mes y nadie te cobra por volver a abrirlo.

No necesitas saber qué es un servidor, ni pedir permisos, ni esperar a que alguien de sistemas instale algo. Si sabes abrir un Excel, sabes usar Analyticraft.

Preview para Desarrolladores

Clona, instala y abre la ventana nativa

  • Node.js versión LTS activa (v20.x o v22.x)
  • Rust y Cargo 1.75+ instalado vía rustup
  • pnpm recomendado, o npm v10+
  • Windows: Microsoft Visual Studio C++ Build Tools y Windows SDK
$ git clone https://github.com/seargentpepper/Analyticraft.git$ cd Analyticraft$ pnpm install   # o npm install$ pnpm run tauri dev   # abre la app nativa$ pnpm run build   # opcional: compila y verifica tipos estrictos

Comparte el conocimiento, no la factura

Analyticraft es MIT y crece con contribuciones, se parte del movimiento Open Source. Reproduce los resultados, comparte el CSV, entrega el dashboard en un archivo y deja que otros sigan contando la historia sin pedir permiso a nadie.
